# Ricardo Guillen I. - Personal Website

This repository contains the source code for my personal portfolio website, showcasing my work as a Front-End Engineer with over 10 years of experience in web development.

You can visit the live website ([https://ryarturogi.github.io/](https://ryarturogi.github.io/)).

## Features

- **Responsive Design:** Fully responsive and optimized for various screen sizes.
- **Tech Stack Expertise:** Highlights my proficiency in TypeScript, React, TailwindCSS, Storybook, and design systems.
- **Social Links:** Links to my LinkedIn, Twitter, and GitHub profiles for professional networking and contributions.
- **Custom Avatar Section:** Displays my avatar with a custom header for an appealing and professional introduction.

## Sections

1. **Header:**  
   Contains my name, title, and a brief description of my expertise.
   
2. **Social Links:**  
   Quick links to my LinkedIn, Twitter, and GitHub accounts.

3. **About Me:**  
   A brief description of my career journey and skills.

4. **Skills Section:**  
   Lists my core competencies in web development and databases.

5. **Footer:**  
   Displays a custom logo with a CTA to get in touch with me for potential opportunities.

## Technologies Used

- **HTML5 & CSS3:** For basic structure and styling.
- **React:** A JavaScript library for building user interfaces.
- **TypeScript:** Strongly-typed JavaScript for ensuring robust code.
- **TailwindCSS:** A utility-first CSS framework for efficient styling.
- **Storybook:** Used for documenting reusable UI components.
- **Vite:** Lightning-fast build tool for modern web projects.
